## Local Visual Editor

The test branch includes `editor.html`, a browser-based GrapesJS editor for previewing and arranging site pages.

1. Run the site through a local HTTP server.
2. Open `/editor.html`.
3. Choose a page from the Page selector; it loads immediately.
4. Edit the page, preview it, then export HTML and CSS.
5. Test the exported files on the test branch before merging changes into `main`.

The editor has no GitHub credentials and cannot write to the repository automatically. Exported files must be reviewed and committed manually.
