[2] Privacy Policy & Client-Side Data Transparency

Sub-Space Link Labs is committed to user privacy, minimalist data architecture, and full operational transparency:

  • No Tracking, Profiling, or Advertising Cookies: This website does not deploy advertising trackers, third-party analytics pixels, tracking cookies, or user fingerprinting scripts.
  • Local Storage (Client-Side Only): Interactive arcade cabinets (such as Cyber-Snake v1 and v2) utilize your browser's local storage (localStorage) strictly to preserve high scores and game initials on your individual device. This data is never transmitted to, collected by, or stored on external servers.
  • Third-Party Telemetry API Requests: The Server Telemetry interface initiates an anonymous, client-side HTTP request to the public api.mcstatus.io service to query Minecraft test server status. No personally identifiable information (PII), credentials, or user-specific payloads are transmitted during this query.
  • Hosting & Server Logs: Standard web server connection logs (such as IP address and user-agent) may be processed transiently by our cloud hosting infrastructure (Netlify / GitHub Pages) solely for network security, DDoS mitigation, and reliable content delivery.
